Sou o **Tiago**, de **Paços de Ferreira (Portugal)**, e estou a dar os primeiros passos como programador.

Tenho explorado várias linguagens, de **C++** e **Java** (programação orientada a objetos e CRUD) até **JavaScript**, **Node.js**, **Express** e **React**, onde já criei o meu primeiro jogo web e uma app de reconhecimento facial.

O meu objetivo é simples: escrever código limpo, construir software fiável e crescer até me tornar um programador que cria coisas que duram.
